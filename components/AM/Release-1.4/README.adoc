# Archetype 1.4

openEHR https://specifications.openehr.org/releases/AM/Release-2.0.6/AOM1.4.html[Archetype 1.4] XML schema - part of openEHR Release-1.0.2.

== Validate an XML instance

Use the repository `scripts/validate-template.sh` scaffold to validate an XML instance against `Template.xsd`:

----
./scripts/validate-template.sh /path/to/template.xml
----

An alternative XSD can be supplied as the second argument. The script requires `xmllint`.
